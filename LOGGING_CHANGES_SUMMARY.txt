CUSTOMIZATION
===============================================================================

To change log levels:

1. Edit: app/logging_config.py (line 20-40)
2. Find the module name in LOG_LEVELS dict
3. Change its logging level (DEBUG, INFO, WARNING, ERROR)
4. Restart: make reset && make up

Examples:

  # Make STT more verbose
  "app.voice.stt": logging.DEBUG,

  # See SQL queries
  "sqlalchemy.engine": logging.DEBUG,

  # Suppress app debug logs
  "app": logging.INFO,
